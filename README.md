# JavaScript Advanced

Repositorio de ejercicios prácticos del curso de JavaScript avanzado.

## Temas

* Promises y programación asíncrona
* `async/await`
* `Promise.all()` y `Promise.race()`
* Funciones generadoras (`function*` y `yield`)
* Manejo de errores y módulos de JavaScript

## Tecnologías

* JavaScript
* Node.js
* Vite
* Git y GitHub

**Objetivo:** fortalecer los fundamentos de JavaScript y desarrollar habilidades aplicables a QA Automation.
